# かけがな (Kakegana)

ミニマル・ダークモード仕様の2D物理パズルゲーム。  
画面中央上部の「白い点」に、五十音表からひらがなを配置して、文字の形やバランスを活かして何個吊り下げられるかを追求します。

---

## ✨ 特徴・操作仕様

1. **ゴースト移動 ＆ 決定による実体化**:
   - 50音表から文字を選んで動かしている間は**半透明の幽霊（ゴースト）状態**となり、物理干渉（衝突）しません。
   - 途中で指やマウスを離しても実体化しません。
   - **画面右下の「決定ボタン」または「Enterキー」を押下した瞬間に初めて実体化**し、操作不能となって物理落下・設置されます。
2. **30°回転ボタン**:
   - 画面右下の**「30°回転ボタン」**を押すと、時計回りに30度ずつ回転します（マウスホイールでも回転可能）。
3. **ゲームオーバー時の演出 ＆ X（旧Twitter）シェア**:
   - 1つでも文字を落とすとゲームオーバー。
   - 決定・回転ボタンが隠れ、**右上にXの公式ロゴボタン**が出現します。
   - Xボタンを押すと、自動的に **「n個のひらがなを引っ掛けました！#かけがな 」** という投稿画面が開きます。
4. **スマートフォン完全対応**:
   - モバイル縦画面での操作性・タッチ領域・セーフエリアを最適化。
   - 画面をドラッグしてゴーストを動かし、右下のボタン群で片手でも快適に回転・決定が可能です。
5. **ミニマル・ダークモード**:
   - 背景は深遠な黒（`#0c0d10`）、文字および支点は純白（`#ffffff`）。
   - 画面上に存在する日本語は「五十音表のひらがな」のみ。
6. **新ゴ Regular & 「ゐ」「ゑ」収録**:
   - モリサワ「UD新ゴ Regular（ウェイト: R）」の正確なグリフパスから幾何学剛体を生成。
   - 全48文字を網羅。

## ☁️ Cloudflare Pages へのデプロイ設定

GitHubリポジトリを Cloudflare Pages に接続する際の設定値：

- **Framework preset**: None / Vite
- **Build command**: `npm run build`
- **Build output directory**: `dist`
- **Node.js version**: `20` (ルートの `.node-version` により自動認識されます)
