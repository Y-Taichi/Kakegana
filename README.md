# かけがな (Kakegana)

ミニマル・ダークモード仕様の2D物理パズルゲーム。  
画面中央上部の「白い点」に、五十音表からひらがなをドラッグして、文字の形やバランスを活かして何個吊り下げられるかを追求します。

---

## ✨ 特徴・操作仕様

1. **ミニマル・ダークモード**:
   - 背景は深遠な黒（`#0c0d10`）、文字および支点は純白（`#ffffff`）。
   - 画面上に存在する日本語は「五十音表のひらがな」のみ。
2. **新ゴ Regular & 「ゐ」「ゑ」収録**:
   - モリサワ「UD新ゴ Regular（ウェイト: R）」の正確なグリフパスから幾何学剛体を生成。
   - 「ゐ」と「ゑ」を含めた全48文字を網羅。
3. **五十音表**:
   - 罫線なし・ボタン枠なしの文字だけが整然と並ぶコンパクトなデザイン。
   - 常に見えている右端は1/3の長さの端が丸い縦線のみ。
4. **ドラッグ ＆ マウスホイール回転**:
   - ドラッグ中も他の文字に物理干渉（衝突・押し引き）可能。
   - 壁のすり抜け・貫通を防止し、文字のカーブに沿って滑らかに滑ります。
   - **マウスホイールでのみ角度が回転**します。
5. **落下時の挙動（鑑賞スクロール）**:
   - 1つでも落としたら五十音表は線ごと左外へ隠れて見えなくなります。
   - 画面をドラッグまたはホイールスクロールして、今までかけた文字の構造を自由に見渡すことができます。
6. **リセット**:
   - 画面下端中央の `[ ↻ Space ]` をクリックするか、`Space` キーを押すと最初からやり直せます。

## ☁️ Cloudflare Pages へのデプロイ設定

GitHubリポジトリを Cloudflare Pages に接続する際の設定値：

- **Framework preset**: None / Vite
- **Build command**: `npm run build`
- **Build output directory**: `dist`
- **Node.js version**: `20` (ルートの `.node-version` により自動認識されます)

## 🚀 ローカル起動方法

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# プロダクションビルド (単一HTML出力)
npm run build
```
